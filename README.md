# CESI Movies

Catálogo de películas y personas para Windows.

## Descargar e instalar

1. Descarga **[CESIMovies-win-Setup.exe](https://github.com/carless/CESIMovies-releases/releases/latest/download/CESIMovies-win-Setup.exe)** (última versión).
2. Ejecútalo. Si Windows muestra «Windows protegió tu PC», pulsa **Más información → Ejecutar de todas formas** (el instalador todavía no está firmado).
3. El instalador instala .NET 8 si hace falta y crea los accesos directos en el escritorio y en el menú Inicio.

Requisito: el **Microsoft Access Database Engine (64 bits)** debe estar instalado en el equipo.

## Actualizaciones

No hace falta volver a descargar nada: al abrir el programa, si hay una versión nueva, te pregunta si quieres instalarla y se actualiza solo. También puedes buscarla desde el panel de información → **Buscar actualizaciones**.

Tus datos (base de datos, imágenes y configuración) se guardan en `%AppData%\CESIMovies` y se conservan al actualizar.
